先读：从CUDA/TIRx到CuTe C++的符号与layout前置知识

  1. 先读本版完整流程图，用具体矩阵元素串起窗口、线程和存储位置；v02起每版另有一张机制放大图。
  2. 修改nk、kt和输出轮round，观察stage/phase；双CTA版本再切换consumer、peer、ei，核对输出坐标。
  3. 点击源码行，把CuTe表达式对应到存储、计算或同步环节。
  4. 自己编译运行，再对照逐行解释；按顺序进入下一版。
